# 飞书多维表格（Bitable）实测行为规格

实测时间：2026-11-17。环境：ego-browser（Chromium），飞书个人版 Web 端（my.feishu.cn），视口用 CDP 固定为 1600×900，界面语言简体中文。
实测对象：在「我的文件夹」新建的空白多维表格「Quiet.md 调研（可删）」，一张数据表，十几个不同类型的字段，25 行示例数据。

约定：

- 「DOM」= 用 `getComputedStyle` / `getBoundingClientRect` 读到的值；「量」= 在 1600×900 的截图上量像素（截图是 1x，误差 ±1px）。
- 位置写成 `[x,y 宽x高]`，都是 CSS 像素，原点在视口左上角。
- 颜色统一写十六进制；`#1f2329/0.15` 表示该色 15% 不透明度。
- 截图都在 `shots/` 下，文中只写文件名。
- 已经在 `../DATA_TABLE.md` 第一节和「二之三」记过的内容不重复，只记新的或有出入的。

## A. 工具栏与各面板

### A0. 工具栏本体（DOM）

截图：`grid-filled.png`

- 工具栏在视图页签条下面，一行，高 40（y=108–148），白底；下边就是表头上边线。
- 左侧按钮从 x=260 起：`添加记录`（蓝字 `#1456f0`，带 `+` 图标，[260,115 84x26]，右边紧贴一个 20 宽的 `⌄` 按钮，两者合成 104×26 的分体按钮，主体圆角 `6 0 0 6`）｜`字段配置`｜`视图配置`｜`筛选`｜`分组`｜`排序`｜`行高`｜`填色`。
- 每个普通按钮：高 26，圆角 6，图标 16，图标与文字间距约 4，文字 14px `#646a73`，文字右内边距 4。四字按钮宽 84，两字按钮宽 56。按钮之间间距 12（例：字段配置 x=378–462，视图配置 x=474 起）。
- 悬停/打开面板时按钮底是 `#1f2329/0.08`。
- 右侧（从右往左）：评论、表内搜索（放大镜带横线图标）｜竖线｜重做、撤销｜竖线｜分享视图箭头、勾选框图标、`生成页面`、`智能提醒`、AI 星形图标。右侧图标按钮 24×24，图标 16，圆角 4。
- **生效态**（按钮文字前面多一个数字，底色随功能不同，DOM）：
  - 筛选生效：文字变成 `1 筛选`，按钮底 `rgba(20,86,240,0.2)`（蓝）。
  - 分组生效：`1 分组` / `2 分组`，底 `rgba(255,129,26,0.15)`（橙）。
  - 排序生效：`3 排序`，底 `rgba(62,195,247,0.2)`（青）。
  - 行高、填色生效时没有数字（行高只是图标换成当前档位的图标）。
- **「你调整了 XX」提示**：只要在当前视图里改了筛选/分组/排序/填色而没有保存，当前视图页签右边会接出一个胶囊：`[图标] 你调整了筛选  清除  保存`（另有「你调整了分组」「你调整了排序」「你调整了填色」）。胶囊 213×28，圆角 20，文字 12px `#646a73`，`清除`、`保存` 是 12px 蓝字文字按钮（32×22）。点 `清除` 撤掉这次调整，点 `保存` 写进视图。见 `filter-applied.png`、`group-stat-menu.png`。
- 面板都是点按钮后在按钮下方弹出，面板顶边 y=145，再点按钮或点面板外关闭；修改即时生效，没有「确定」按钮（排序关掉自动排序时例外，见 A6）。

**各字段类型的运算符（原文，按下拉顺序）**：

| 字段类型 | 运算符 | 值控件 |
|---|---|---|
| 文本 | 等于、不等于、包含、不包含、为空、不为空 | 文本输入框，占位「请输入」 |
| 单选 | 等于、不等于、包含、不包含、为空、不为空 | 选项下拉，占位「请选择选项」（下拉里顶部「查找选项」搜索框 + 彩色标签列表，行高 32） |
| 多选 | 等于、不等于、包含、不包含、为空、不为空 | 同上，可多选 |
| 日期 / 创建时间 / 最后更新时间 | 等于、晚于、早于、为空、不为空 | 两段：日期模式下拉（100×32）+ 日期输入（110×32，占位 `yyyy/mm/dd`） |
| 数字 / 货币 / 进度 / 评分 / 自动编号 | 等于、不等于、大于、大于或等于、小于、小于或等于、为空、不为空 | 输入框，占位「请输入」 |
| 电话号码 | 等于、不等于、大于、大于或等于、小于、小于或等于、为空、不为空（实测如此，和数字一样） | 输入框 |
| 复选框 | 没有运算符下拉 | 一个复选框（勾 = 已勾选，不勾 = 未勾选） |
| Email / 超链接 | 等于、不等于、包含、不包含、为空、不为空 | 输入框 |

- 运算符下拉面板宽 204，行高 30（6 项时高 198，8 项 262，5 项 166）。

**日期的相对值**（日期模式下拉，面板宽 200）：

- 运算符「等于」时 12 项：`具体日期`、`今天`、`明天`、`昨天`、`本周`、`上周`、`本月`、`上月`、`过去 7 天内`、`未来 7 天内`、`过去 30 天内`、`未来 30 天内`。
- 运算符「晚于」「早于」时 4 项：`具体日期`、`今天`、`明天`、`昨天`。
- 选「具体日期」时右边是日期输入框，点它弹出月历（见 C 节）。

**生效**：选好值立即生效，表格只剩匹配行、行号重新从 1 排；底部计数变成匹配数（「6 条记录」）；工具栏变 `1 筛选`（蓝底）；视图页签旁出现「你调整了筛选 清除 保存」。

### A5. 分组

截图：`group-empty.png`、`group-one-level.png`、`group-two-levels.png`、`group-grid.png`、`group-stat-menu.png`、`group-collapsed.png`

**面板** 宽 518（[411,145 518x…]），内边距 `16px 0`：

- 标题 `设置分组条件` + `?` 图标。空状态只有一个 `选择条件 ⌄` 选择器（98×32，占位色 `#8f959e`），没有其它文案。
- 选了字段后变成条件行（行高 38，行距 10）：拖动点（16px `#646a73`）｜字段选择器｜顺序分段控件（228×38：底 `#f5f6f7`、圆角 6、内边距 4；两段各 106×22；选中段是白色滑块 109×28、圆角 5、描边 `#1f2329/0.15`，文字 14px/600 `#1456f0`；未选段文字 `#646a73`）｜删除 `×`（24×24）。
- 分段控件的文案随字段类型变：
  - 单选/多选：`选项顺序`｜`选项倒序`
  - 日期、数字：`0 → 9`｜`9 → 0`
  - 文本：`A → Z`｜`Z → A`

- 有分组时底部出现蓝字 `另存为新视图`。
- 日期字段分组是按**具体日期值**分（每个不同日期一组），面板里没有「按周/月」之类的选项。

**表格里的样子**（量，`group-collapsed.png`）：

- 表头下方先空 16px（底 `#fcfcfc`），然后是第一组。
- 组头行：高 32，白底，上下各 1px `#dee0e3`。从左到右：折叠箭头（`⌄` 展开 / `›` 折叠，约 10px，`#646a73`，x≈266–276）；分组值——单选/多选用和单元格一样的彩色标签（x=286 起），日期/文本直接是 14px 文字；冻结区右端是统计 `9 条记录 ⌄`（12px `#646a73`，文字右端距冻结线约 13px）。

- 每组末尾有一行「＋」添加行（32 高）。
- 组与组之间空 16px（`#fcfcfc`）。
- 二级分组：子组整体向右缩进 20px（子组头、行号、添加行都右移 20），子组头同样 32 高；子组之间同样空 16px。

### A6. 排序

截图：`sort-empty.png`、`sort-three.png`、`sort-auto-off.png`

- 面板宽 518（[477,145 518x…]），和分组面板是同一套组件。
- 标题 `设置排序条件` + `?`；空状态只有 `选择条件 ⌄`。
- 加了条件后，标题行右侧出现 `自动排序` 开关：文字 12px `#646a73` + 开关 40×22（开 = `#1456f0`，圆形滑块 18×18）。默认开。

## C. 各类型单元格：展示态与编辑态

### D1. 选中与选区

截图：`cell-selected.png`、`range-dragging.png`、`range-selected.png`、`range-shift-click.png`、`range-shift-arrow.png`

- 单格选中：2px `#1456f0` 描边（画在格子边线上，向内外各占 1px），右下角一个填充柄：约 6×6 的蓝色方块外加 1px 白边（整体 8×8，中心在格子右下角）。所在行整行变浅蓝 `#e7eefd`，行号格换成「拖动点 + 复选框」。

  - 左下角的记录计数变成 `已选择 12 个单元格 ⌄`；

- 点行号处的复选框选中整行：行底 `#e7eefd`，复选框蓝底白勾；左下角变成 `已选择 2 条记录 ⌄`；多行选中后**没有**可见的浮动操作条（DOM 里有一个 `已选 2 行 | 复制 | ×` 的条，但 `visibility:hidden`，实测不显示），批量操作走右键菜单。截图 `rows-selected.png`。
