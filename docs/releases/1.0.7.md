# Fei Notes 1.0.7 beta

## English

- Start writing while iCloud account discovery runs in the background. Verified
  cached libraries open directly, and a late cloud reply preserves local editing.
- Share an original note while keeping its identity and location in My Documents.
  Stopping sharing preserves the latest content under the original note ID.
- Share a folder and its nested contents, including future notes. Confirm access
  before moving private notes into a shared folder.
- Organize shared shortcuts in personal folders that sync between your own Macs
  without changing who has access.
- Refine collaboration controls for both themes: an anchored invitation card and
  avatars in Feishu, and the system share icon and centered invitation in Notes.
- Add verified cloud checkpoints, reference-based attachment collection and
  selective attachment downloads. Offline edits retain their merge history;
  reusing a collected attachment uploads its bytes before the note reference.

Update all Macs used for beta cloud testing to this build. Earlier beta cloud
writers are not supported with the new checkpoint envelope. TestFlight includes
cloud access without a subscription. Boards still merge at scene/block-property
level. Real multi-account folder sharing, revocation during editing and large
physical-device reinstall timing remain acceptance work, not measured claims.

## 简体中文

- 启动时在后台连接 iCloud，等待期间即可写本机笔记；已确认的缓存可直接打开，晚到的云端结果不会切走正在编辑的内容。
- 直接共享原笔记，保留其在“我的文档”中的位置与身份；停止共享时，最新正文回到原笔记。
- 支持共享文件夹及嵌套内容，也涵盖以后新增的笔记；移入私人笔记前确认访问范围。
- 共享入口可用个人文件夹整理，并在自己的 Mac 之间同步，不改变共享权限。
- 协作界面适配两种主题：飞书主题使用锚定邀请卡和头像，备忘录主题使用系统分享图标和居中邀请卡。
- 新增经过验证的云端快照、按引用回收附件与按需下载；保留离线合并历史，重新引用已回收的附件时先补传文件再同步正文。

请将参与云测试的所有 Mac 一起更新；不支持此前测试版与新快照格式混合写入。TestFlight 云功能无需订阅。画板仍按场景/块属性合并；真实双账户文件夹共享、编辑中撤销权限及实机大库重装耗时仍需验收。
