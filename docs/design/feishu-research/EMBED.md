# 飞书云文档（docx）内嵌多维表格：实测

实测时间：2026-11-18。环境：ego-browser（Chromium），飞书个人版 Web 端（my.feishu.cn），视口 1161×795（CSS 像素，DPR 2；截图按 1x CSS 像素导出），界面语言简体中文。
实测对象：在「我的文件夹」新建的云文档「Quiet.md 内嵌表格调研（可删）」，正文一段文字后用 `/` 插入一个新多维表格。

约定：

- 「DOM」= `getComputedStyle` / `getBoundingClientRect` 读到的值；「量」= 在 1x 截图上逐像素读的颜色/坐标（误差 ±1px），表格网格本体是 canvas，只能这样量。
- 位置写成 `[x,y 宽×高]`，原点在视口左上角。文档正文列左边 x=163，宽 820。
- 截图都在 `shots-embed/` 下，已裁掉页面顶栏和文档作者行（含头像、姓名）。
- 颜色写十六进制；`#1f2329/0.08` 表示该色 8% 不透明度。

## 0. 插入

- 正文空行输入 `/多维表格` → 弹出「多维表格」分组，五项：`关联已有多维表格`、`表格`、`看板`、`甘特图`、`画册`（即按初始视图类型新建）。截图 `insert-slash-menu.png`。
- 选「表格」→ 先出现一个占位块 `[163,277 820×221]`（量）：底 `#f2f3f5`、1px 描边 `#dee0e3`、圆角约 6（四角有抗锯齿）、正中一个灰色转圈，约 3–5 秒后换成真实表格。截图 `embed-loading.png`。
- 新表默认 3 个字段（`文本`（主字段，带锁形图标）、`文本 2`、`单选`）、3 条空记录。
- 用 TSV 粘贴 8 行 × 3 列：先弹「提示 / 是否将粘贴内容的第一行识别为字段名？」（`不识别` / `识别为字段名`）；选「不识别」后写入 8 条记录。注意：**粘贴把「单选」字段改成了文本类型**（字段图标变成文本图标），后面重新改回单选。

## 1. 静止状态（鼠标不在表格上、未选中）

操作：点表格上方正文，把鼠标移到页面空白处。截图 `embed-rest.png`。

**整体**

- 内嵌块 = `.embeded-bitable-container` `[163,277 820×412]`（DOM），宽度等于正文列宽 820，左右与正文对齐。容器 `border-radius: 6px`，但**没有背景、没有描边、没有阴影**（DOM 全是 0/none）。整块只有两部分：头部 52 + 网格 canvas 360。
- 与上一段正文：正文行底 ≈ 260，块顶 277（块外的 docx 段距，量）。

**头部（`.bitable-docx-embed-toolbar-visual-header`，DOM）**

- `[163,277 820×52]`，白底 `#ffffff`，无边框、无分隔线，只有**一行**。
- 静止时头部只有一个元素：左侧「视图名下拉」`[161,291 80×28]`，圆角 4、无底色：
  - 视图类型图标（表格视图是网格图标）：图标盒 24×24，svg 16×16，色 `#2b2f36`，在 x=167；
  - 文字 `表格`（= 当前视图名，不是数据表名）：14px / 22px / 400 / `#1f2329`，x=189；
  - 下拉箭头：svg 12×12，色 `#2b2f36`，紧跟文字（x=222）。
  - 其后有一个 24×24 的「编辑」图标位 `[241,293]`，`opacity: 0`（静止时不可见，悬停视图名时出现，见 2）。
- 头部右侧在静止时**完全空白**（工具按钮只在悬停/选中时出现）。
- 没有数据表名、没有视图页签条、没有「+ 新建视图」、没有记录数。
- **变体：头部左侧多出多维表格名。** 刚插入时头部只有视图名；在用「在多维表格中打开」打开过一次独立页面（以及从块手柄选中过整个块）之后，头部常驻变成 `[多维表格图标 16×16] 未命名多维表格 ｜ [表格图标] 表格 ⌄`（刷新页面后仍如此）。DOM：名字 14px / 22px / 400 `#1f2329`，图标 x=163、文字 x=185；分隔线 `.bitable-doc-divider` 1×12 `#dee0e3`，在 x=294；视图下拉随之右移到 x=302。触发条件没能确定（见 9）。截图 `embed-rest-with-base-name.png`。

**网格（canvas `[163,329 820×360]`，量）**

- 网格外框 1px：左、右、底 `#dee0e3`；顶线（字段标题行上沿，y=329）`#e6e8ea`。外框是直角，没有圆角、阴影。
- 字段标题行高 36（329→365），白底；字段名 14px `#1f2329`，字段类型图标 `#646a73`；标题行左端是全选复选框（`#8f959e`）。
- 数据行高 32；行分隔线 `#dee0e3`，从 x≈181 开始（行号列左侧留白 18 不画线）；行号 `#8f959e`，单元格文字 `#1f2329`。
- 冻结列（主字段）右边线更深：`#bbbfc4`（x=477）；其他列分隔线 `#dee0e3`。
- 最后一列右侧是一个 145 宽的空列，标题行里是 `+`（`#8f959e`，新增字段）。
- 数据行下面是一行「新增记录」行（32 高，左端 `+` `#8f959e`），它下沿 y=652 就是网格外框底边。
- **底部**：外框之下 36px 高的统计条，在主字段列内靠右：`8 条记录 ⌄`（12px 左右、`#646a73`，文字框 `[404,663 62×12]`），没有边框和底色。点它是统计方式下拉（见 4）。
- 默认高度：**按内容撑高**。3 条记录时 canvas 高 200（块总高 ≈ 252），8 条时 360（块总高 412）。见 8。

## 2. 鼠标悬停在表格上

操作：鼠标移到网格某个单元格上（不点）。截图 `embed-hover.png`、`embed-hover-tooltip.png`、`embed-hover-title.png`。

多出来的元素：

1. **左侧块手柄**（文档统一的 block handle，挂在全局 overlay 上）：`[115,292 42×26]`，白底、1px `#dee0e3` 描边、圆角 6；内含多维表格品牌图标（22×22 盒，紫色 `#a45eeb` 的 svg 14×14）和 6 点拖动手柄（svg 14×14，`#8f959e`）。它在正文列左边外侧（块左边 163 往左 48），垂直对齐头部中线。点它是 docx 的块菜单（本次未点开）。
2. **头部右侧浮动工具栏**（`.bitable-float-toolbar-wrapper`，DOM `[719,280 264×48]`，右对齐到块右边 983）：一排 8 个 24×24 纯图标按钮，图标 svg 16×16、色 `#2b2f36`，按钮圆角 4、静止无底、悬停底 `#1f2329/0.08`，按钮间距 8（每格 32）。从左到右（tooltip 原文）：
   `字段配置`、`视图配置`、`筛选`、`分组`、`排序`、`行高`、｜分隔线｜、`评论`、｜分隔线｜、`在多维表格中打开`。
   分隔线 1×24，`#dee0e3`。没有文字按钮，没有「…」更多。tooltip 黑底白字，出现在按钮正上方（高 36）。
3. 悬停的那一行（到最后一个字段为止，不含右侧空列）底色变 `#f4f4f4`（量），行首出现 6 点拖动柄和复选框（替换行号），主字段单元格右侧出现 `查看`（展开记录，带图标、描边小按钮）和 `+`。
4. 悬停视图名时：视图名底色 `#1f2329/0.08`（圆角 4），右侧出现「编辑」图标按钮（重命名视图，24×24，图标 `#646a73`）。

头部高度不变（仍 52），工具栏和视图名同一行，不增加行。网格本身无变化。

## 3. 点进表格 / 选中单元格后

操作：单击第 3 行「文本 2」单元格；然后把鼠标移出表格。截图 `embed-selected-hover.png`（选中 + 鼠标仍在块上）、`embed-selected.png`（选中 + 鼠标移开）。

- **头部不因选中而变化**：DOM 里头部结构与静止时完全一样（仍只有视图名下拉），没有出现新的一行工具栏，也没有带文字的按钮。
- 右侧那排 8 个图标按钮**只跟鼠标悬停走**：鼠标在块上时出现（和 2 完全相同），鼠标一离开块，即使单元格仍处于选中状态，浮动工具栏的 DOM 也被移除（`.bitable-float-toolbar-wrapper` 查不到），左侧块手柄也消失。
- 选中只体现在网格里（量）：所在行（到最后一个字段为止）底色 `#e7eefd`；当前单元格白底 + 2px `#1456f0` 描边（右下角有一个蓝色小方块填充柄）；行首出现拖动柄 + 复选框 + 主字段里的 `查看` / `+`（仅鼠标在块上时）。
- 选中单元格时文档正文的光标消失（焦点进了表格），docx 本身没有给整个块加选中框。

## 7. 筛选 / 排序生效时头部怎么提示

操作：筛选加条件「单选 等于 进行中」，排序加「文本 A→Z」。截图 `embed-filtered-hover.png`、`embed-filtered-rest.png`、`embed-unsaved-settings.png`、`embed-saved-settings.png`。

- 生效的按钮变成「图标 + 数字」：按钮宽 24 → 34（DOM），右侧多一个数字角标（不是上标，同一行的普通文字）`1`，14px / 22px，色 `#336df4`；图标变蓝 `#1456f0`；按钮常驻底色 `#1f2329/0.08`（量得 `#edeeee`），圆角 4。筛选、排序都是同一种样式；分组未实际应用，按类推应相同（未验证）。
- 同时出现一个带文字的描边按钮 **`保存配置`**：`[829,292 74×24]`，14px `#1f2329`，1px `#d0d3d6` 描边，圆角 6，位于「行高」右边、分隔线左边。说明在文档里改的筛选/排序先是临时的；点「保存配置」后写进视图，按钮消失，工具栏缩回，筛选/排序按钮的蓝色 + 数字保留。
- 工具栏因此变宽、整体向左延伸（仍右对齐到块右边 983）。
- 提示只在浮动工具栏上：鼠标离开块后工具栏仍会隐藏（复测：悬停→移开后 `.bitable-float-toolbar-wrapper` 被移除），**静止状态的头部没有任何「已筛选」提示**，只能从记录数（`3 条记录`）看出来。例外：刚关闭某个面板后、鼠标还没再进出过块时，工具栏会一直留着（`embed-filtered-rest.png` 就是这种情况）。
- 记录变少时块随之变矮（3 条时 canvas 高 ≈ 200）。

## 5. 视图切换

- **内嵌块里没有视图页签条**。视图入口只有头部左侧的「视图名下拉」（图标 + 视图名 + ⌄），一次只显示当前视图的名字。
- 操作：点视图名 → 向下弹出视图列表（DOM `.bitable-sidebar-wrapper` `[163,325 240×115]`，左边与块左边对齐，白底、1px `#dee0e3`、圆角 6、阴影 `0 4px 8px rgba(31,35,41,.1)`）。截图 `view-menu.png`、`view-menu-two-views.png`。
  - 每行 `[168,y 230×32]`，圆角 4：6 点拖动柄（可排序）+ 视图类型图标 + 视图名 + 右侧 `…`。
  - 当前视图：文字和图标 `#1456f0`，14px / 500；其他视图：`#1f2329`，14px / 400；悬停行底 `#1f2329/0.08`（量得浅灰）。没有勾号。
  - 列表下一条分隔线，底部一行 `+ 新建 ▾`（14px / 400 `#1f2329`）。悬停/点它向右弹出子菜单：`表格视图`、`看板视图`、`甘特视图`、`画册视图`（各带图标）。截图 `view-new-menu.png`。
  - 视图行的 `…` 菜单：`重命名`、`复制视图`、`删除视图`（各带图标）。截图 `view-more-menu.png`。
  - 点列表里另一个视图即就地切换，块内容换成该视图，下拉关闭。
- 新建视图后：自动切过去，并在头部把视图名变成**就地输入框**（DOM `[187,291 120×28]`，1px `#1456f0` 描边、圆角 6、16px、内边距 `1px 12px`，默认名「看板」已全选），回车确认。截图 `view-rename-inline.png`。悬停视图名时出现的「编辑」图标按钮也是进这个就地改名。
- 视图名下拉的选中/未选中只体现在这个弹出列表里；头部本身只有一种样式（`#1f2329` 14px / 400，无底色；悬停底 `#1f2329/0.08`）。

**看板视图在内嵌块里**（截图 `kanban-rest.png`、`kanban-hover.png`）：

- 块高 332 = 头部 52 + canvas 280（DOM）。头部仍只有「看板图标 + `看板` ⌄」；头部下方有一条 1px 分隔线 `#efeff1`（量，y=328，x 179–966），表格视图没有这条（表格视图由网格自己的上边线顶住）。
- 分组列：宽 256、间距 8，第一列从 x=183 开始（离块左边 20）；列底色按选项颜色浅化（`#f4f7ff` 蓝、`#fff7ef` 橙、`#edfafe` 青，量）；列头：选项标签 + 记录数（`#646a73`）+ 右侧 `…` 和 `+`；列底一行居中 `+`（新增卡片）。
- 卡片白底、1px `#e8e9e9` 描边、左右内缩 8，卡片之间 4；卡片显示主字段（粗）和其他字段值。
- 列高固定（canvas 280，列 334→590）：「进行中」3 张卡只露出 2 张，第 3 张要在列内滚动——看板不按内容撑高。
- 悬停时浮动工具栏变成 5 个按钮（tooltip）：`卡片配置`、`分组依据`、`筛选`、`排序`、｜、`在多维表格中打开`。没有「评论」「行高」「视图配置」。新建后「卡片配置」图标是蓝色带底（`#1456f0`），原因未确认（可能是新视图的引导高亮）。

## 6. 展开 / 全屏

- **文档内没有「全屏」或「展开」整个表格的入口。** 头部浮动工具栏、块手柄菜单、视图菜单里都没有全屏项。
- 唯一的「展开」是浮动工具栏最右的 `在多维表格中打开`（图标：方框带右上箭头，tooltip 原文就是这六个字）。点击 → **在浏览器新标签页**打开独立多维表格页面 `https://my.feishu.cn/base/<base token>?table=<table id>&view=<view id>`，当前文档页不变；那边是完整的多维表格（左侧数据表列表「数据表」、视图页签 `表格`/`看板`、完整工具栏、自动化等）。返回 = 关掉/切回原标签页，没有「返回文档」按钮。截图 `open-in-bitable.png`。
- 头部出现多维表格名时（见 1 的变体），点名字也是同样在新标签页打开独立页面；悬停 tooltip `前往多维表格查看`，悬停底 `#1f2329/0.08`，光标 pointer。截图 `embed-hover-base-name.png`。
- 单条记录可以就地展开：悬停行时主字段单元格右侧的 `查看`（tooltip `弹窗打开`）→ 文档上盖一层灰色遮罩，中间弹出记录详情弹窗（约 `[190,60 781×675]`，量），顶部 `⌃ ⌄`（上一条/下一条）、`分享`、`关注`、`…`、`×`；内容为记录标题、`详情`/`历史` 页签、字段列表、`+ 新增字段`。与独立多维表格的记录弹窗相同。点 `×` 关闭回到文档。截图 `record-modal.png`。
- 块手柄（左侧 42×26 的白色小块）点开是 docx 通用块菜单：`缩进 ›`、`收起`、｜`评论`、`删除`｜`分享`、`复制链接`｜`在下方添加 ›`。点开时整个块被选中：网格+统计条外面套一圈 2px `#c2d4ff` 的选中框（量，范围 y=329→689，即不包括 52 高的头部），浮动工具栏消失。截图 `block-handle-menu.png`、`embed-block-selected.png`。

## 8. 高度 / 宽度，内容超出时

- 宽度：固定等于正文列宽（820，左右与正文对齐）。没有找到左右拖宽的把手；块手柄菜单里也没有宽度选项。（docx 的「宽屏模式」会改变整列宽度，本次没切。）
- 高度（表格视图）：**没有可拖的高度把手**（沿块下沿 / 右沿逐点读 `cursor`，都是 default/text；DOM 里找不到 resize 类元素）。高度完全**按内容撑高**：块高 = 头部 52 + 标题行 36 + 32×记录数 + 新增行 32 + 统计条 36。实测 3 条 → 252、8 条 → 412、34 条 → 1244、120 条 → 3996，没有上限，不出现块内纵向滚动，整个文档变长。
- 超长时的替代方案是**粘性头部**：块滚到视口上沿以后，52 高的头部（`position: sticky; top: 0; z-index: 1`，无阴影无底线）和字段标题行一起吸顶在文档滚动区顶部，直到块底部离开。悬停时吸顶头部里照样出现浮动工具栏。截图 `embed-sticky-header.png`。
- 看板视图相反：canvas 高固定 280（块高 332），每个分组列内部纵向滚动，卡片多了也不撑高（见 5）。
- 列多时的横向滚动本次没测（只有 3 个字段，没撑满 820）。

## 9. 表格名称

- **数据表名（「数据表」）在内嵌块里任何状态都不显示**，也没有数据表切换器。头部的名字有两种：
  - 视图名（`表格`、`看板`）：一直显示，可以就地改名（悬停出现的编辑图标，或新建视图时自动进入；输入框样式见 5）。
  - 多维表格（base）名（`未命名多维表格`）：只在 1 所说的变体里显示；**不能就地改名**，点它是在新标签页打开独立多维表格。
- 背后的事实：插入「多维表格」时飞书**在云盘里新建了一个独立的多维表格文件**（名为「未命名多维表格」，云盘「我的文件夹」列表里能看到它），文档里的块只是引用它的一张数据表 + 视图。这个文件需要和调研文档一起手动删除。
- 多张数据表时怎么切换：**未测**。内嵌块的视图下拉只列出当前数据表的视图；要测需要在那个独立多维表格里加第二张数据表，超出「只在这篇文档里操作」的范围，没做。从界面看内嵌块没有任何数据表切换入口，一个块对应一张数据表。

## 10. 内嵌状态下新增记录的入口

1. 网格最后的「新增记录」行：左端 `+`（`#8f959e`），整行可点；悬停时该行（到最后一个字段为止）底色 `#f2f3f5`、`+` 底下一小块 `#d9dcdf`（量）。截图 `embed-sticky-header.png`（底部那行就是悬停态）。
2. 右键任一行 → `向上插入 [1] 行`、`向下插入 [1] 行`（数字可改），另有 `分享此记录`、`复制记录链接`、`查看详情`、`添加子记录`、`添加评论`、`删除记录`。截图 `row-context-menu.png`。
3. 悬停行时主字段单元格里的 `+`（tooltip `添加子记录`）——是加子记录，不是加同级记录。截图 `row-hover-actions.png`。
4. 粘贴多行 TSV 时自动追加记录（会先问是否把第一行当字段名，见 0）。
5. 看板视图：每列底部居中的 `+`，以及列头右侧的 `+`。
- **头部没有「+ 新增记录」按钮**（独立多维表格工具栏最左的 `+ ⌄` 在内嵌头部里没有）。
