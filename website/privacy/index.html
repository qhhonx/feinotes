隐私政策

笔记保存在你的 Mac 上。你可以开启 iCloud 同步，也可以选择与他人共享。

保存在 Mac 上的内容

笔记、附件、文件夹、回收站和设置保存在你的 Mac 上。使用本机文档库无需创建飞记账户。

导入时，飞记会读取你选择的文件。导出和备份的位置由你决定。备份中也可能包含共享笔记的本机副本和待同步改动。

iCloud 同步与共享

开启 iCloud 后，笔记、附件、文件夹和改动记录会通过 Apple 的 CloudKit 保存到你的 iCloud 私有数据库。飞记使用 iCloud 账户标识区分不同账户的文档库。设备名称、在线状态，以及协作时的光标和选区，也会通过 CloudKit 同步。

邀请他人时，你填写的 Apple 账户邮箱会交给 CloudKit 查找收件人。对方只能按授予的权限访问共享副本及其附件，其他笔记和设置仍留在各自的文档库中。

TestFlight 测试期间，云功能无需试用或订阅。正式商店版本会在你主动开始试用时，将开始时间记入 iCloud 私有数据库。订阅付款由 Apple 处理，飞记通过 StoreKit 验证购买和到期状态，用于开通云功能或恢复购买。

网络图片与外部链接

笔记中的网络图片由图片所在的网站提供。自动下载开启时，该网站会收到加载请求，其中可能包含你的 IP 地址等网络信息。你可以在「设置 → 通用」关闭「自动下载网络图片」，之后按需点按加载。

打开外部链接后，相关网站会按其隐私政策处理访问。

官网由 GitHub Pages 托管，GitHub 会处理 IP 地址等访问信息。详情见 GitHub 隐私声明。

诊断与问题反馈

飞记在 Mac 上保存启动、同步和错误日志，日志可能包含文件路径。应用自身不会自动将这些本机日志发送给飞记支持。

通过 TestFlight 测试时，Apple 会收集并向开发者提供崩溃报告和使用信息，以及你主动提交的反馈。这些信息用于排查问题和改进飞记。详情见 TestFlight 隐私说明。

通过邮件或 Telegram 联系支持时，你发送的消息、截图和日志会由相应平台处理，并用于回复和排查问题。

删除与备份

删除的笔记会在回收站保留 30 天，也可以提前彻底删除。同步记录、共享副本和已导出的备份可能有各自的保留周期，清空回收站不会同时清除这些副本。

切换到本机文档库、退出 iCloud 或取消订阅，都会保留已有的 iCloud 数据。共享笔记的所有者可以撤销他人的访问权限；对方已经另存的副本需要由对方处理。具体操作见删除笔记或停止同步。
