## 2026-11-19 的简化（用户定的）

- **一个文件就是一张表**（Notion 的模型）：界面不再有「数据表」切换、新建、删除，内嵌页头部压到 40pt。文件格式不变：`.sqlite` 仍能装多张表，界面只认 block 指定的那张（默认第一张），别的表原样留在文件里。
- 「关联」「查找引用」不再出现在新建字段的类型里（它们要引用文件里的另一张表）；已有的照常显示和编辑。以后要连两类数据，做跨文件关联。
- 去掉画册视图（`gallery.rs` 删了，要找回看 git 历史）；旧文件里的画册视图按表格视图打开。
- 再进一步：**一张表只有一个表格视图**，去掉多视图（视图页签、视图菜单、新建视图）和看板视图（`kanban.rs` 删了）。看板卡片拖动换位置的最后版本没进过提交，存在 `target/archive/kanban.rs.2026-11-19`，删之前的完整改动在 `target/archive/bitable-before-single-view.2026-11-19.patch`。文件里已有的多个视图、看板视图原样保留，界面显示 block 指定的那个（默认第一个），一律画成表格。引擎（`ViewKind`、`add_view` 等）没动。
- 独立页一行：左边工具图标，右边撤销、重做、搜索、「…」。内嵌页：图标加名字（页内新建的表可以双击改名），工具悬停时出现。新表默认叫「未命名数据表」。
- 「导入 CSV 为新数据表」去掉了（它往文件里加表）。
- 新表默认五列文本：文本 1 … 文本 5。
- 主页和文件夹卡片把数据表画成迷你表格（`home.rs` 的 `thumb_blocks` 里 `BlockKind::DataTable`），笔记里嵌的表格也一样。

## 怎么看

- 预览：`cargo build --release && scripts/preview.sh`（用的是真实文档库）。侧栏「新建 › 数据表」建一个独立的 `.sqlite`；文档里输入 `/数据表`（`/shujubiao`）插入一个表格 block。
- 一份内容丰富的示例：`cargo run --release -p fdl_core --example table_demo -- <某个文档库目录>/项目管理.sqlite`（两张互相关联的表、公式、查找引用、4 个视图）。再加一个数字参数是 n 行的大表（压测）。
- 脚本回放：`cargo build --release --features devtools`，然后照 tools/harness/README.md 跑；库目录里先放一个上面生成的 `.sqlite`。

## 做成了什么

**引擎** `crates/core/src/table/`（不依赖 GPUI，wasm 下也能编，只是没有 `sqlite`）：

| 文件 | 内容 |
|---|---|
| `model.rs` | Base / Table / Field / Record / View / Value；22 种字段类型（文本、单选、多选、人员、日期、附件、数字、复选框、超链接、公式、查找引用、自动编号、电话、Email、地理位置、条码、进度、货币、评分、关联、创建时间、最后更新时间） |
| `field.rs` | 每种类型的解析、显示、排序、类型互转；日期和数字格式；按内容推断列类型 |
| `ops.rs` | 所有修改都是 `Op`，执行返回逆操作；`Doc` 管撤销重做和「哪些东西还没写进文件」（`Dirty`） |
| `actions.rs` | 界面要的编辑动作：增删行列、改字段类型（单元格自动转换）、双向关联的镜像维护、粘贴、填充、视图和表的增删改 |
| `calc.rs` | 计算列重算（公式、查找引用、自动编号、创建/更新时间），跨表按依赖顺序，循环引用显示 `#循环引用` |
| `formula/` | 公式：手写词法 + 解析 + 求值，100 个函数（逻辑 15、数字 29、文本 25、日期 23、其它 8），字段引用写 `{名}` / `[名]` / 裸名字 |
| `query.rs` | 筛选（且/或，各类型的运算符，相对日期）、多条件排序、最多 3 级分组（可折叠）、统计、填色、表内搜索、看板分栏。10 万行筛选 + 两级排序 22 ms |
| `sqlite.rs` | 读写 `.sqlite`：表名、列名、选项名就是界面上看到的；改一格只写一行；别的程序改过的文件、没有说明表的普通 SQLite 文件都能读。10 万行 × 12 列：新建 131 ms，读 125 ms，改 100 行后保存 10 ms |
| `csv.rs` | CSV/TSV 读写、导入成新表（推断类型）、导出、Markdown 表格、全文搜索用的纯文本 |
| `sample.rs` | 示例数据库和大表 |
| `fuzz_tests.rs` | 随机操作：任何序列全部撤销回到起点、重做回到终点、结构始终合法 |

**界面** `src/table/`：

- `mod.rs`：`BaseState`（一个打开的文件，同一文件的多个视图共用，改动后 0.4 秒写盘，每 2 秒看一次文件有没有被别的程序改过）、`TableView`（一个视图）。
- `grid.rs`：表格视图。只画看得见的行；冻结列；区域选择（拖动、⇧ 点击、⇧ 方向键）；填充柄；拖列宽；拖表头换列序；拖行换序；分组头折叠；底部统计栏；滚动条。
- `cell.rs` / `editors.rs`：各类型单元格的显示和编辑：文本类就地编辑，选项下拉（搜索、新建、改名、改色、删除），日期月历，关联记录选择，附件列表。
- `menus.rs`：数据表和视图页签（改名、复制、删除、新建视图）、工具栏、表内搜索、行多选操作条、字段菜单、单元格右键菜单、统计菜单、「…」菜单（导入导出 CSV、复制为 Markdown）。
- `panels.rs`：字段配置、筛选、分组、排序、行高、填色六个面板。
- `fields.rs`：新增 / 修改字段表单，每种类型各自的设置，公式编辑器（即时校验、函数和字段参考）。
- `record.rs`：记录详情侧栏。`kanban.rs`：看板（拖卡片换栏）。`gallery.rs`：画册。
- `keys.rs`：键盘（方向键、Tab、Enter、直接打字进入编辑、Delete、⌘Z/⇧⌘Z、⌘C/⌘X/⌘V、⌘A、⌘F、空格展开记录），复制粘贴是制表符分隔的文本，能和 Excel 互相粘贴。

**接入**：

- `BlockKind::DataTable(TableRef)`，DocxXML 写成 `<datatable src="…" table="…" view="…" height="…"/>`，`all-blocks.xml` 里有规范写法。block 只是引用，数据在文件里。
- 文档里的表格 block（`src/editor/datatable.rs`）：就地显示、就地编辑，底边可拖高度，「全屏」占满笔记区（顶栏面包屑「文档名 › 数据表」，点文档名或「退出全屏」返回）。文件放 `.assets/<uuid>.sqlite`。
- 独立文件：`DocKind::Table`，扩展名 `.sqlite`；侧栏和文件夹页「新建 › 数据表」；侧栏、搜索、主页卡片有图标；内容进全文搜索；创建副本是复制文件；改名后视图跟着文件走。
- 导出：Markdown 和 HTML 里写成普通表格（当前视图，按其筛选排序）。
- 界面文案都有英文（`settings.rs`，227 条）。
- 依赖：rusqlite 0.43（自带 SQLite 3.54.1），THIRD_PARTY.md 已登记。

## 没做或没验证的（那剩下的 1%，其实不止）

**写了但没有实际点过**（逻辑自查过，界面行为未验证）：

- 面板里面的操作：加筛选条件后选字段 / 运算符 / 值，分组、排序、填色的增删，字段配置里拖动换序。
- 字段表单的「确定」：新增各类型字段、改类型、公式编辑器、关联和查找引用的设置。
- 填充柄、拖列宽、拖表头换列序、拖行换序、看板拖卡片。
- 记录详情里的就地编辑；附件的添加和图片封面。
- 复制粘贴（只在脚本的模拟剪贴板路径上写了，没跑）；CSV 导入导出。
- 面包屑点文档名返回（脚本点偏了，「退出全屏」同一条路径也没点）。
- 深色模式；Windows 和 Linux（rusqlite 的 bundled 编译应该没问题，没试）。

**已知问题和欠缺**：

- 选中单元格后直接打中文：第一个按键按原始字符进格子，输入法组合不对。先双击（或按 F2）再打字没问题。
- 日期带时间的字段，月历里没有时间输入框；要改时间只能直接打字（`2026-11-18 09:30`）。
- 文本单元格是单行编辑；多行只能在记录详情里写。
- 日历、甘特、表单视图没有做（新建视图菜单里只有表格、看板、画册）。
- 「行即页面」的「文档」字段类型（V2 文档 2.3）没做；文件夹笔记作为数据来源、xlsx 导入、飞书导出文件导入没做。
- 复制一个含表格 block 的文档、复制粘贴 block：两处指向同一个 `.sqlite`（改一处另一处跟着变）。删除文档不会删 `.assets` 里的表格文件。
- 版本历史不管 `.sqlite`；多窗口同时改同一个表格文件时，后写的整行覆盖先写的，没有冲突提示。
- 查找引用在飞书上的配置界面没测到（被引导弹窗挡住），是按常识做的。
- 示例数据里「剩余天数」公式对已过期的任务显示 `#NUM!`（DATEDIF 起始晚于结束）。
- 表格 block 在打印 / PDF 里走 HTML 那条路，没看过效果。
- 「开始指南」里没有加数据表的介绍，README 和 docs/ARCHITECTURE.md、docs/FORMAT.md 没更新。
- 横向滚动条压在最后一行上（位置在统计栏上方 2px）。

## 和 DATA_TABLE_V2.md 的出入

- 关联字段的单元格存的是对方记录 id 的 JSON 数组（`[3,7]`），没有建连接表。
- 每张 SQL 表的固定列是 `id`、`_order`（整数行序，不是分数索引）、`_meta`（创建/修改时间和自动编号的 JSON）。
- 界面按用户后来的要求照飞书做（`feishu_theme` 的色板和实测尺寸），V2 文档第四节「外观是自己的」那段作废。
- 没有按 Teable 源码移植：引擎是按需求自己设计的，公式函数表和筛选运算符参考了飞书实测和 Teable / Airtable 的通行做法。
